# Courier Management System

A simple web-based Courier Management System developed as a student project.

## Features

- Courier booking form
- Sender and receiver details
- Standard and express delivery selection
- Automatic tracking ID generation
- Courier tracking
- Courier records table
- Responsive design for mobile and desktop

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

Open `index.html` in a web browser.

## Project Purpose

This project demonstrates the basic design and functionality of a courier booking and tracking system using front-end web technologies.
